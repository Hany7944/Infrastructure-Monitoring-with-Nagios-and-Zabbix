Infrastructure Monitoring 

📌 DESCRIPTION

A comprehensive, hands-on project focused on building and configuring a centralized monitoring system using Nagios and Zabbix. 
The project covers designing the monitoring architecture, where a Nagios and Zabbix server monitors a set of virtual machines within a multi-tier environment (app01, db01, web01, mc01, mav01,and rmq01). 

The purpose is to empower engineers to transition from reactive to proactive infrastructure management: 
unifying system visibility, detecting failures as they occur, and monitoring resource 

performance to avoid downtime and ensure the stability of critical application services.

🛠️ PREREQUISITES

• Monitoring Platform: Nagios Server and Zabbix Server
• Visualization & Management: Zabbix Web Interface (Frontend)
• Monitoring Database: MySQL / MariaDB
• Data Collection: Zabbix Agents (Active & Passive Checks)
• Operating System: Linux Virtual Machines (CentOS Stream 9 / Ubuntu)
• Monitored Services: Nginx (web01), Apache Tomcat (app01), MariaDB (db01), Memcached (mc01), RabbitMQ (rmq01)
• Infrastructure Baseline: The multi-tier VProfile environment built (Vagrant & Oracle VirtualBox)

Project Focus: Manual Infrastructure Provisioning | Multi-Tier Architecture | Shell Scripting | Java Application Deployment | DevOps
